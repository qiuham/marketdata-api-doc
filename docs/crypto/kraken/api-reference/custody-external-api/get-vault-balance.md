# Get vault balance

> Returns the total balance for a vault valued in the requested quote currency. The response includes the 24-hour balance change and any assets for which a quote rate was unavailable.

This is an aggregate valuation only. It does not break down which assets the vault holds or in what quantity. For per-asset quantities, including the spot, hold, available, staked, and pledged components, call `GET /v0/insto/custody/vaults/{vault_id}/assets/balances`.

**Rate limit:** 200 requests per 30 seconds per IP.
