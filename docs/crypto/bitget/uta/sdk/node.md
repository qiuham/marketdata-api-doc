# Node.js

Official Node.js SDK for the Bitget API.

**Code path**:`src/lib/v2`

## Install

```bash
npm i bitget-api-node-sdk
```

## Usage

Initialize an API client with your credentials:

```ts
import BitgetResetApi from "bitget-api-node-sdk";

const api = new BitgetResetApi.MixOrderApi(apiKey, secretKey, passphrase);
```

More: [Node.js SDK](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-node-sdk-api)
