# September 2026

## [September 24, 2026] Get Elite Records: Added bizTime response parameter

Interface:
- `/api/v3/earn/elite-records`

Changes:
- Added `bizTime` String response parameter under `recordList[]`: Business time.

## [September 24, 2026] Account Channel: Added balanceOriginal push parameter

Interface:
- WebSocket Account channel

Changes:
- Added `balanceOriginal` String push parameter under `data[].coin[]`: New coin balance, calculated without deducting borrowing-related amounts. The existing `balance` parameter remains unchanged.

## [September 23, 2026] Get Account Assets: Added balanceOriginal response parameter

Interface:
- `/api/v3/account/assets`

Changes:
- Added `balanceOriginal` String response parameter under `assets[]`: New coin balance, calculated without deducting borrowing-related amounts. The existing `balance` parameter remains unchanged.


## [September 22, 2026] Added Delete Sub-account API

**New API:**

- `/api/v3/user/delete-sub` Delete Sub-account: Delete a virtual or normal sub-account (main account only; requires assets across all business lines not exceeding 10 USDT, no MT5 account opened, and no in-progress orders).

## [September 22, 2026] Added Manual Borrowing APIs for Unified Trading Account

**New APIs:**

- `/api/v3/account/borrow` Borrow: Manually borrow a specified amount of a specified coin.
- `/api/v3/account/max-borrowable` Get Max Borrowable: Query the maximum borrowable amount for each coin.
- `/api/v3/account/set-repay-mode` Set Repay Mode: Set the repayment mode for manual borrowing (`auto`/`manual`).

**Changes:**

- Get Account Setting (`/api/v3/account/settings`): Added `repayMode` String response parameter (repayment mode).
- Get Account Assets (`/api/v3/account/assets`): Added `interestBase` String response parameter under `assets[]` (interest calculation base).

## [September 20, 2026] Get Instruments: Corrected minOrderAmount description

Interface:
- `/api/v3/market/instruments`

Changes:
- Corrected the `minOrderAmount` response parameter description: unit is USDT (previously incorrectly described as "in terms of the quote coin").

## [September 17, 2026] Update Ad: Rate limit increased from 1/sec/UID to 3/sec/UID

Interface:
- `/api/v3/p2p/ad-update`

Changes:
- Rate limit updated from 1/sec/UID to 3/sec/UID.

## [September 17, 2026] Set Collateral Type: Added allowCashplus request parameter

Interface:
- `/api/v3/account/set-collateral-type`

Changes:
- Added `allowCashplus` String optional request parameter: whether to enable Cash+ as collateral. `yes` Enable; `no` Disable.

## [September 17, 2026] Added 17 Copy Trading Follower APIs

**New APIs:**

- `/api/v3/copy/futures/portfolio-overview` Get portfolio overview of the lead trading project
- `/api/v3/copy/futures/follower-settings` Create a copy trading subscription
- `/api/v3/copy/futures/modify-follower-settings` Modify copy trading subscription settings
- `/api/v3/copy/futures/unfollow` Cancel a copy trading subscription
- `/api/v3/copy/futures/copy-settings` Query copy trading settings
- `/api/v3/copy/futures/copy-transfer` Transfer funds into or out of the copy trading account
- `/api/v3/copy/futures/copy-transfer-record` Query copy trading account transfer records
- `/api/v3/copy/futures/current-copy` Get current copy trading information
- `/api/v3/copy/futures/copy-profit-details` Get copy trading profit sharing records
- `/api/v3/copy/futures/close-positions` Manually close a copy trading position
- `/api/v3/copy/futures/close-all` Close all copy trading positions
- `/api/v3/copy/futures/current-positions` Get current copy trading positions
- `/api/v3/copy/futures/place-tpsl` Set take-profit/stop-loss for a copy trading position
- `/api/v3/copy/futures/modify-tpsl` Modify take-profit/stop-loss for a copy trading position
- `/api/v3/copy/futures/cancel-tpsl` Cancel take-profit/stop-loss for a copy trading position
- `/api/v3/copy/futures/current-tpsl-orders` Get current copy trading TP/SL orders
- `/api/v3/copy/futures/tpsl-order-history` Get historical copy trading TP/SL orders

## [September 17, 2026] Get CFD Tickers: Added ask1/bid1 response parameters and split openPriceChange

Interface:
- `/api/v3/cfd/market/tickers`

Changes:
- Added `ask1` String response parameter: best ask price.
- Added `bid1` String response parameter: best bid price.
- Replaced `openPriceChange` with `askOpenPriceChange` and `bidOpenPriceChange` String response parameters: change in the ask/bid opening price respectively.

## [September 17, 2026] Place Order/Batch Order/Modify Order/Batch Modify Order: Added pxAmendType request parameter

Interface:
- `/api/v3/trade/place-order`
- `/api/v3/trade/place-batch`
- `/api/v3/trade/modify-order`
- `/api/v3/trade/batch-modify-order`
- WebSocket `place-order` / `batch-place` / `modify-order` / `batch-modify` channels

Changes:
- Added `pxAmendType` String optional request parameter: order price amendment type. `no` The order is rejected if the price exceeds the price limit range (default); `yes` the system adjusts the price to the best value within the limit range and places the order. Only applicable to limit orders.

## [September 17, 2026] Create Sub-account API Key: Now supports Copper custody sub-accounts

Interface:
- `/api/v3/user/create-sub-api`

Changes:
- Clarified that in addition to virtual sub-accounts, the creation of API Keys for Copper custody sub-accounts is now also supported.

## [September 15, 2026] Get Account Fee Rate: Added rpiFlag request parameter

Interface:
- `/api/v3/account/fee-rate`

Changes:
- Added `rpiFlag` String optional request parameter: RPI fee rate flag. `yes` Yes; `no` No. For market maker users to get fee rates for RPI-enabled trading pairs. Invalid for non-market-maker users. Default: `no`

## [September 15, 2026] Get Fee Group: Added rpiMakerFeeRate response parameter

Interface:
- `/api/v3/market/fee-group`

Changes:
- Added `rpiMakerFeeRate` String response parameter: RPI maker fee rate in decimal form, e.g. `0.0001` means 0.01%. Applies to market maker users and only available for trading pairs with RPI enabled.

## [September 11, 2026] CFD Trading Guide: Added supported API features and trading mode/instrument code rules

- Updated the [CFD Trading Guide](/docs/uta/cfd-trading-guide) page: added the supported API features section and the trading mode and instrument code rules section, and updated the related support article links.

## [September 10, 2026] Get Account Setting: Added deltaSwitch response parameter

Interface:
- `/api/v3/account/settings`

Changes:
- Added `deltaSwitch` String response parameter: Delta-neutral mode switch. `no` Delta-neutral mode disabled; `yes` Delta-neutral mode enabled.

## [September 10, 2026] Get Instruments: Added maxMarketOrderAmount response parameter

Interface:
- `/api/v3/market/instruments`

Changes:
- Added `maxMarketOrderAmount` String response parameter: Maximum order amount for a single market order. This is only applicable for spot trading pairs; not returned for futures trading pairs.

## [September 10, 2026] Added CFD Trading Guide

**New Guide:**
