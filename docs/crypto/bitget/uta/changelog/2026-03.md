# March 2026

## [March 31, 2026] Move Positions API is now available on Unified Trading Account

New API:<br/>

- /api/v3/account/move-positions: Move positions between accounts within the same master-sub account system
- /api/v3/account/move-position-history: Query move position history

This feature allows whitelisted users to transfer futures positions (USDT/USDC futures, cross-margin mode only) between
master and sub-accounts without going through the matching engine. The move price defaults to mark price, no trading
fees are charged, and the trades will not appear in public market data.<br/>

## [Mar 26, 2026] Update on the regular release schedule

- To improve system stability, our backend’s regular release window has been adjusted to **Tuesdays and Thursdays, 14:
  00–18:00** (excluding emergency releases).<br/>
- During the regular release window, the **REST API** may return error responses such as **45001, 40725, 40808**. Please
  **retry** after receiving these errors.<br/>
- **WebSocket** connections may be disconnected during the release. Please add a **reconnection mechanism** in your
  code. Before disconnecting, WebSocket will send an error message (error code: **30033**, error message: **“Service
  upgrade in progress. Connection reset imminent. Please reconnect”**) to notify the client that the connection is about
  to be reset. After receiving this message, the client should reconnect.

  


## [March 16, 2026]  Added Fast Fill WebSocket Channel

WebSocket:<br/>
Changes：<br/>

- Added Fast Fill Channel (fast-fill) - A streamlined version of the private fill channel with fewer parameters and
  lower latency. Pushed directly from the matching engine rather than through the counter. Only pushes order fill data
  for users in UTA mode. Does not currently push strategy and copy trading fill data.


## [March 12, 2026] Retail Price Improvement (RPI) orders are now available on Unified Trading Account (UTA).

new API: /api/v3/market/rpi-orderbook<br/>
new channel: rpi order book

Please refer to <a href="https://www.bitget.com/support/articles/12560603867770"> Bitget Retail Price Improvement (RPI)
Orders </a> for more details.


## [March 12, 2026] Support querying basic/advanced account mode information

API:<br/>

- /api/v3/account/settings

Changes:<br/>
A new field `accountLevel` has been added to indicate the account level: `basic` (Basic mode) and `advanced` (Advanced
mode).


## [March 11, 2026] Fee Sign Adjustment for the “Get Trade Fills” API

API:<br/>

- /api/v3/trade/fills

Changes:<br/>
To align with the WebSocket trade-fill channel pushes, we have unified the sign convention for fees in trade fills. The
current fee sign convention in the trade-fill REST API is:

- fee < 0: The platform pays the user (the user receives a rebate).
- fee > 0: The user pays the platform (the user pays a trading fee).


## [March 3, 2026]  Launch of Market Maker Fee Rate API Query

API:<br/>

- /api/v3/market/fee-group Get market maker fee rate groups
- /api/v3/market/score-weights Get market maker score weights

# 2026 年 3 月

## [3月31日, 2026] 统一交易账户（UTA）上线仓位转移功能

新增接口:<br/>
- /api/v3/account/move-positions: 在同一母子账户体系内进行仓位转移
- /api/v3/account/move-position-history: 查询移仓历史记录

该功能仅对白名单用户开放，支持通过母账户API Key在同一账户体系内（母子、子子）进行合约仓位转移（仅支持USDT/USDC合约全仓模式），移仓价格默认为标记价格，不产生手续费，移仓交易不会出现在公有行情成交中。 <br/>

## [3月11日, 2026] 获取成交明细 API 手续费正负号调整

接口:<br/>
- /api/v3/trade/fills

调整内容:<br/>
为了与 WebSocket 成交明细频道推送保持一致，我们统一了成交明细（fills）里手续费的正负号规则。
成交明细 REST API 手续费正负号当前规则：
- fee < 0：平台支付给用户费用（用户收到返佣）。

- fee > 0：用户支付给平台费用（用户支付手续费）。
