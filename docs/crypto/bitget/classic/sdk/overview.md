# SDK

Bitget provides official SDKs to help you integrate the Bitget API in your preferred language. Each SDK wraps authentication (API Key signing), REST requests, and WebSocket connections, so you can focus on your business logic.

## Official SDKs

| Language | Link |
|:---------|:-----|
| Java | [bitget-java-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-java-sdk-api) |
| Python | [bitget-python-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-python-sdk-api) |
| Node.js | [bitget-node-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-node-sdk-api) |
| Golang | [bitget-golang-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-golang-sdk-api) |
| PHP | [bitget-php-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-php-sdk-api) |
| Postman | [upex-postman-openapi](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/upex-postman-openapi) |

All SDKs live in the [v3-bitget-api-sdk](https://github.com/BitgetLimited/v3-bitget-api-sdk) repository. Select a language in the left sidebar for installation and usage details.

# SDK

Bitget 提供官方 SDK，帮助开发者用熟悉的语言接入 Bitget API。每个 SDK 封装了鉴权（API Key 签名）、REST 请求与 WebSocket 连接，让你专注于业务逻辑。

## 官方 SDK

| Language | Link |
|:---------|:-----|
| Java | [bitget-java-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-java-sdk-api) |
| Python | [bitget-python-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-python-sdk-api) |
| Node.js | [bitget-node-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-node-sdk-api) |
| Golang | [bitget-golang-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-golang-sdk-api) |
| PHP | [bitget-php-sdk-api](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/bitget-php-sdk-api) |
| Postman | [upex-postman-openapi](https://github.com/BitgetLimited/v3-bitget-api-sdk/tree/master/upex-postman-openapi) |

所有 SDK 都位于 [v3-bitget-api-sdk](https://github.com/BitgetLimited/v3-bitget-api-sdk) 仓库。在左侧边栏选择一种语言，查看安装与使用说明。
