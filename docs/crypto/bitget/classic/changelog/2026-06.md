# June 2026

## [June 23, 2026] Subaccount Withdrawal: Updated supported coins for `coin` parameter

Interface:
- `/api/v2/broker/account/subaccount-withdrawal`

Changes:
- Removed `TON` from the supported coin list of `coin` request parameter
- Added `GRAM` and `BGB` to the supported coin list of `coin` request parameter

## [June 16, 2026] Get Withdrawal Records / Get Deposit Records: Updated chain field description

Interface:
- `/api/v2/spot/wallet/withdrawal-records`
- `/api/v2/spot/wallet/deposit-records`

Changes:
- Updated `chain` response parameter description: chain name format is now consistent with the `chain` field returned by `/api/v2/spot/public/coins`
