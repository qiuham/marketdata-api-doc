# January 2025

## [January 16, 2025] The futures contract financial record has added an enumeration for the futureTaxType parameter.

**Endpoints:** :/api/v2/tax/future-record<br/>
Additional content:
- Add the enumeration type and description for the return value parameter `futureTaxType`

## [January 15, 2025] Bitget to adjust the calculation of USDC-M perpetual futures index price from USD to USDC

Key adjustments
- Index price and mark price: The index price and mark price of USDC-M perpetual futures will now be denominated in USDC.
- Order book prices: Order book prices for USDC-M perpetual futures will also be denominated in USDC.

For more details, please refer to: https://www.bitget.com/support/articles/12560603820643

# 2025 年 1 月

## [1月16日, 2025] 合约财务记录增加futureTaxType参数枚举

接口：/api/v2/tax/future-record<br/>
新增内容：

## [1月15日, 2025] Bitget 关于 USDC 永续合约指数价格由 USD 计价调整为 USDC 计价的公告

主要调整
- 指数价格和标记价格：USDC 永续合约的指数价格和标记价格将采用 USDC 报价。
- 订单簿报价：USDC 永续合约的订单簿报价也将采用 USDC 计价。

详情请参考：https://www.bitget.com/zh-CN/support/articles/12560603820643
