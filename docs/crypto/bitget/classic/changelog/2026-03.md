# March 2026

## [March 27, 2026] Added Classic Account On-Chain Elite Earn APIs

API:
- /api/v2/earn/elite/product Get On-Chain Elite product list
- /api/v2/earn/elite/assets Get On-Chain Elite asset information
- /api/v2/earn/elite/records Get On-Chain Elite subscription details
- /api/v2/earn/elite/subscribe-info Get On-Chain Elite historical records
- /api/v2/earn/elite/subscribe On-Chain Elite subscription
- /api/v2/earn/elite/subscribe-result Get On-Chain Elite subscription result
- /api/v2/earn/elite/redeem-info Get On-Chain Elite redemption information
- /api/v2/earn/elite/redeem On-Chain Elite redemption

## [March 12, 2026] The query range for the broker (agent) API has been uniformly extended to 90 days.

API:<br/>
- /api/v2/broker/customer-commissions
- /api/v2/broker/customer-trade-volume
- /api/v2/broker/customer-list
- /api/v2/broker/customer-deposit
- /api/v2/broker/sub-customer-list

## [March 12, 2026] Add a new API to Get Agent SubCustomer List

API:
- /api/v2/broker/sub-customer-list
