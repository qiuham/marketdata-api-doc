# October 2026

## [October 16, 2026] Spot Depth APIs: Discontinued rToken Query Support

Interface:
- `/api/v2/spot/market/orderbook`
- `/api/v2/spot/market/merge-depth`

Changes:
- Effective October 17, 2026, these endpoints no longer support querying rToken data.
- To query rToken depth, please migrate to the v3 depth endpoint `/api/v3/account/reality-orderbook`.
- This endpoint requires API Key authentication. Please contact your account manager to apply for whitelist access in advance.

# 2026 年 10 月

## [10月16日, 2026] 现货深度接口不再支持 rToken 查询

接口:<br/>
- `/api/v2/spot/market/orderbook`<br/>
- `/api/v2/spot/market/merge-depth`<br/>

调整内容:<br/>
- 自 2026 年 10 月 17 日起，以上接口不再支持查询 rToken 数据。<br/>
- 如需查询 rToken 深度，请迁移至 v3 深度接口 `/api/v3/account/reality-orderbook`（获取 Reality 深度数据）。<br/>
- 该接口需要 API Key 认证，请提前联系您的客户经理申请开通白名单权限。<br/>
