# July 2026

## [July 29, 2026] Added VIP Rate Limit Rules

**New Doc:**

- Added VIP Rate Limit Rules, describing API rate limits by VIP level.

## [July 23, 2026] V2 Positions Channel: Added cashDividend push parameter

Interface:
- V2 WebSocket `channel=positions`

Changes:
- Added `cashDividend` String push parameter: Cash dividend, unit: USDT

## [July 21, 2026] Get Single Position / Get All Positions / Get Historical Position: Added cashDividend response parameter

Interface:
- `/api/v2/mix/position/single-position`
- `/api/v2/mix/position/all-position`
- `/api/v2/mix/position/history-position`

Changes:
- Added `cashDividend` String response parameter: Cash dividend, the unit is USDT
