# March 2025

## [March 27, 2025] Updates include new fields in futures contract & funding rate interfaces' return values, and adjusted input params for spot transaction details.

Endpoints:/api/v2/mix/account/accounts <br/>
Additional content:
- The return value of the futures contract account interface has been updated with a new field `available`, which represents the maximum transferable amount of combined margin in the current currency.

Endpoints:/api/v2/mix/market/current-fund-rate <br/>
Additional content:
- The return value of the interface for obtaining the current funding rate has been updated with new parameters, including fundingRateInterval, upper and lower limits of funding rate, and next update time.

Endpoints:/api/v2/spot/trade/fills <br/>
Changes content:
- The `symbol` in the request parameters has been changed from required to optional.

## [March 22, 2025] New Response Fields in Futures Account Channel

Channel: Futures - Private Channel - Account Channel<br/>
Change: Add "crossedRiskRate"(Risk ratio in cross margin mode) and "unrealizedPL"(Unrealized PnL) in push data

## [March 20, 2025] For Spot get order information endpoints, it is adjusted to only support to get the order data within 2 hours when queried by `clientOid`

Endpoints: Spot get order info interfaces<br/>
Change: Querying order information based on `ClientOid` only supports to get the data within last 2 hours.

## [March 18, 2025] Adjust the input parameter instructions for modifying the ApiKey permissions of a sub-account.

**Endpoints:** :/api/v2/broker/manage/modify-subaccount-apikey <br/>
Changes content:
- Modify the sub-account ApiKey permissions: The input parameter permType (permission type) has been changed to a required field.

## [March 12, 2025] Adjustment to the period input parameter for obtaining contract initiative buying and selling volume information.

**Endpoints:** :/api/v2/mix/market/long-short <br/>
Changes content:
- Change the input parameter period field from `1d` to `1Dutc`.

## [March 11, 2025] API for new OI position limit information in contracts

**Endpoints:** :/api/v2/mix/market/oi-limit <br/>
Additional content:
- API for new OI position limit information in contracts

# 2025 年 3 月

## [3月27日, 2025] 合约账户信息接口、资金费率接口返回值新增字段；现货成交明细入参调整；

接口：/api/v2/mix/account/accounts <br/>
新增内容：
- 合约账户接口信息返回值新增联合保证金当前币种最大可转出 `available` 字段。

接口：/api/v2/mix/market/current-fund-rate <br/>
新增内容：
- 获取当前资金费率接口返回值新增 结算周期、资金费率上下限、下次更新时间参数。

接口：/api/v2/spot/trade/fills <br/>
变更内容：
- 请求参数中的`symbol`由必填修改为非必填。

## [3月22日, 2025] Websocket 合约账户频道新增响应字段

频道：合约 - 私有频道 - 账户频道<br/>
改动点：推送信息新增"crossedRiskRate"（全仓时风险率）和"unrealizedPL"（未实现盈亏）字段

## [3月20日, 2025] 现货订单查询类接口, 根据`ClientOid`可查询订单信息调整为只能查询2小时内数据

接口：现货查询订单信息类接口<br/>
改动点：通过`ClientOid`只能查询2小时内订单信息

## [3月18日, 2025] 修改子账户ApiKey权限 入参说明调整

接口：/api/v2/broker/manage/modify-subaccount-apikey <br/>
变更内容：
- 修改子账户Apikey权限 入参 `permType` 权限类型 改为必填。

## [3月12日, 2025] 获取合约主动买卖量信息 period入参调整

接口：/api/v2/mix/market/long-short <br/>
变更内容：
- 入参 `period` 字段 `1d` 改为 `1Dutc`。

## [3月11日, 2025] 合约新增OI 限仓信息API

接口：/api/v2/mix/market/oi-limit <br/>
新增内容：
- 合约新增OI 限仓信息API。
