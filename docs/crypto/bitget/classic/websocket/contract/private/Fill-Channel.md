# Fill Channel

Data will be pushed when order filled.

### Description

Trade details channel

Data will be pushed when order filled.

<div className="api-aligning">

```json title="Request Example"
{
    "op": "subscribe",
    "args": [
        {
            "instType": "USDT-FUTURES",
            "channel": "fill",
            "instId": "default"
        }
    ]
}
```

### Request Parameters

| Parameter | Type | Required | Description                                                                                                                                | 
| :---- | :---- |:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| op | String | Yes      | Operation, subscribe unsubscribe                                                                                                           |
| args | List&lt;Object&gt; | Yes      | List of channels to request subscription                                                                                                   |
| &gt; channel | String | Yes      | Channel name: `fill`                                                                                                                       |
| &gt; instType | String | Yes      | Product type<br/>`USDT-FUTURES` USDT-M Futures<br/>`COIN-FUTURES` Coin-M Futures<br/>`USDC-FUTURES` USDC-M Futures                         |
| &gt; instId | String | No       | Product ID or default，<br/>delivery contract reference：https://www.bitget.com/api-doc/common/release-note#optimization-of-delivery-futures |

</div>

# 成交明细

推送规则：首次订阅不推送，订单发生成交时推送

### 描述

订阅成交明细信息

推送规则：首次订阅不推送，订单发生成交时推送

<div className="api-aligning">

```json title="请求示例"
{
    "op": "subscribe",
    "args": [
        {
            "instType": "USDT-FUTURES",
            "channel": "fill",
            "instId": "default"
        }
    ]
}
```

### 请求参数

| 参数名 | 参数类型 | 是否必须 | 描述                                                                          | 
| :---- | :---- |:-----|:----------------------------------------------------------------------------|
| op | String | 是    | 操作, subscribe unsubscribe                                                   |
| args | List&lt;Object&gt; | 是    | 请求订阅的频道列表                                                                   |
| &gt; channel | String | 是    | 频道名                                                                         |
| &gt; instType | String | 是    | 产品类型                                                                        |
| &gt; instId | String | 否    | 产品名或default，交割合约参考：https://www.bitget.com/zh-CN/api-doc/common/release-note |

</div>

<div className="api-br-10"></div>

<div className="api-aligning">

```json title="订阅返回示例"
{
    "event": "subscribe",
    "arg": {
        "instType": "USDT-FUTURES",
        "channel": "fill",
        "instId": "default"
    }
}
```

| &gt; instId | String | 产品名或default |
