# Introduction

The Binance Convert API allows users to automate their trading on Binance Convert. Users can access the Convert API to integrate automated trading workflows and execute Convert trades programmatically.

**Note: All users of this service are subject to the Binance Terms of Use. The use of the API services is not suitable for purposes including price arbitrage, high frequency trading, or price exploitation. Binance may restrict or terminate a Binance API connection at any time for any reason at its sole discretion and is not obliged to provide prior notice of any such restriction or termination.**
