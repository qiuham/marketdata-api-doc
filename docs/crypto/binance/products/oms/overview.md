# OMS Toolkit

OMS Toolkit is a solution for order management system providers, API trading platforms, bridges, bot
trading platforms, and non-custodial trading providers who connect to Binance as a software service
through their end users' API keys.

This solution generates custom tags that enable trade tagging for spot and futures, supporting user
activity tracking and data analytics for trades executed on Binance.

![OMS trade tagging flow: a Binance user trades through a software service provider, which executes into Binance, and the resulting activity is captured by the OMS dashboard](./images/oms-trade-tagging-flow.png)

Once integrated, the OMS provider can view the activity of users trading through its system, tag
trades by user, strategy, bot, or platform identifier, and use the resulting data for analytics,
reporting, and rebate attribution where applicable.

The dashboard is at
[https://www.binance.com/en/vip/oms-toolkit/dashboard](https://www.binance.com/en/vip/oms-toolkit/dashboard).

This documentation outlines how the trade tagging workflow operates and how OMS providers can use it
to gain better visibility into user trading activity.

For the partner-facing walkthrough — becoming a Link & Trade partner, setting up your Link ID, and
querying rebate stats — see
[How to Set Up the API Link ID?](https://www.binance.com/en/support/faq/detail/a78a065d0c4846aaa1af474d8e712ab9)
