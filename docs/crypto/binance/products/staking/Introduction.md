# Introduction

Binance Staking API is a comprehensive set of endpoints that allows users to seamlessly manage their
staking activities. This API supports multiple staking options, including ETH Staking, SOL Staking,
On-Chain Yields and Soft Staking, enabling users to participate in the proof-of-stake (PoS)
consensus mechanisms of the Ethereum and Solana networks, as well as access a curated selection of
on-chain protocols to stake and earn yields.

# 概述
