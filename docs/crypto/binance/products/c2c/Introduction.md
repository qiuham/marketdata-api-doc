# Introduction

## Binance C2C Endpoints

C2C is also known as Binance P2P. Use these endpoints to query your C2C (P2P) trade history,
including both buy and sell orders.

---

# 概述

币安C2C接口。C2C即币安P2P，可通过这些接口查询您的C2C（P2P）交易历史记录，包含买入和卖出订单。
