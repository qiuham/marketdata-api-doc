# Get Balance

Use the Binance Link wallet user-assets API to query a user's available crypto balance before an
institutional sell flow.

## When to use

Use this before the Sell flow to show the user's available crypto balance and validate that the user
has enough crypto before requesting or executing a sell quote.

## API reference

For balance lookup, refer to the Binance Link wallet
[`user-assets` API](/catalog/core-trading-wallet/api/rest-api/asset#user-asset) agreed for your
institutional integration.

## Recommended sell-flow usage

1. Complete user onboarding and obtain the required `userId`.
2. Query the user's available crypto balance through Binance Link wallet `user-assets`.
3. Use [Get Crypto List for Sell](2.get-crypto-list-for-sell.md) and
   [Get Trading Pair](3.get-trading-pair.md) to confirm the selected asset and target fiat currency
   are supported.
4. Use [Get Fiat/Crypto Amount Limit](4.get-fiat-crypto-amount-limit.md) to validate the selected
   amount.
5. Use [Get Quote](5.get-quote.md) and [Execute Quote](6.execute-quote.md) to continue the sell
   flow.

## Implementation note

Use the balance response only as a pre-check. The final order execution result should still be
handled through Execute Quote, [Get Single Transaction](7.get-single-transaction.md), transaction
list query, and webhooks.
