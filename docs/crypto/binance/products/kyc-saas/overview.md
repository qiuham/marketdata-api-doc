# Binance Link KYC SaaS

Binance Link KYC SaaS is a KYC-as-a-Service solution designed for our Crypto-As-A-Service (CAAS)
clients.

It enables clients to integrate KYC verification for sub-accounts, offering services such as
collecting and validating customer information, auditing customer data, and screening for sanctions
and politically exposed persons (PEPs).

## Where to go next

| If you need                     | Go to                                                                     |
| ------------------------------- | ------------------------------------------------------------------------- |
| Sub-account setup               | [CAAS Getting Started](/products/caas/getting-started)                    |
| Base endpoint and request rules | [Environments and API base URLs](/products/kyc-saas/basics/1.base-urls)   |
| Signing your requests           | [API request signing](/products/kyc-saas/basics/2.request-signing)        |
| Error codes                     | [Error code](/products/kyc-saas/basics/3.error-code)                      |
| Webhook notifications           | [Webhook](/products/kyc-saas/webhook/webhook)                             |
| The endpoint reference          | [KYC SaaS REST API](/catalog/vip-and-institutional-kyc-saas/api/rest-api) |

:::note

KYC SaaS runs on the sub-accounts created in [CAAS Getting Started](/products/caas/getting-started)
and has no separate account setup of its own.

:::
