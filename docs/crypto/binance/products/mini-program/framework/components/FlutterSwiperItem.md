# SwiperItem

Only can be placed inswiper component, width and height are automatically set to 100%.

## Props

| Name                      | Type      | Description                                                                                                                                                          | Default |
| ------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `item-id`                 | `string`  | The id flag of the swiper item                                                                                                                                       |         |
| `skip-hidden-item-layout` | `boolean` | Whether to skip the undisplayed slider layout, set to true Improves sliding performance in complex situations, but loses layout information for hidden state sliders | `false` |
