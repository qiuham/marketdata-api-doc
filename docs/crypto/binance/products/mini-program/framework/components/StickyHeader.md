# StickyHeader

StickyHeader container msv >= 4.35

**Example**

bxml

```html
<sticky-header>
  <view class="header" style="background-color: red;"></view>
</sticky-header>
```

## Props

| Name         | Type     | Description                                                                                        | Default     |
| ------------ | -------- | -------------------------------------------------------------------------------------------------- | ----------- |
| `offset-top` | `number` | Specifies the style class to press down on. when hover-class="none" There is no click state effect | `0`         |
| `padding`    | `array`  | Specifies whether to prevent this node's ancestor from clicking                                    | `[0,0,0,0]` |
