# bn.createLottieContext

▸ **createLottieContext**(`lottieId`): `AnimationItem`

**`description`** return a lottie instance for given lottie id

**`remark`** supported jssdk >= 4.34.0

**`example`**

```js
const lottieContext = bn.createLottieContext("lottie");
