# bn.revokeBufferURL

▸ **revokeBufferURL**(`url`): `void`

**`description`** Revoke the url to buffer and free the used memory space.

**`example`**

```ts
const url = bn.createBuffer(buffer, { extension: "svg" });
bn.revokeBufferURL(url);
```

Parameters

| Name  | Type     |
| :---- | :------- |
| `url` | `string` |

Returns

`void`
