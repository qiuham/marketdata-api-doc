# bn.env

• **env**: `Env`

**`description`** Environmental variable in mini program. Changes according to environment.

**`example`**

```ts
const userDataPath = `${env.USER_DATA_PATH}/path`;
```

## Interface: Env

| Name                 | Type     | Description |
| :------------------- | :------- | :---------- |
| API_HOST?            | `string` |             |
| SITE_HOST?           | `string` |             |
| STATIC_HOST?         | `string` |             |
| STATIC_HOST_SHARE?   | `string` |             |
| USER_DATA_PATH?      | `string` |             |
| WS_HOST?             | `string` |             |
| SENSORS_SERVER_HOST? | `string` |             |
| SENSORS_SERVER_PATH? | `string` |             |
