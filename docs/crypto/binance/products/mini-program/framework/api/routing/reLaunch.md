# bn.reLaunch

▸ **reLaunch**(`options`): `Promise`<`void`\>

**`description`** Close all pages and open to a specified page within the Mini Program.

**`example`**

```ts
bn.reLaunch({
  url: "/pages/example/index",
});
```

Parameters

| Name          | Type     |
| :------------ | :------- |
| `options`     | `Object` |
| `options.url` | `string` |

Returns

`Promise`<`void`\>
