# bn.navigateBack

▸ **navigateBack**(`options`): `Promise`<`void`\>

**`description`** Close the current page and navigate back to the previous page or to a specified
page in the page stack.

**`example`**

```ts
bn.navigateBack({
  delta: 1,
});
```

Parameters

| Name      | Type                                 |
| :-------- | :----------------------------------- |
| `options` | `undefined` \| { `delta`: `number` } |

Returns

`Promise`<`void`\>
