# bn.redirectTo

▸ **redirectTo**(`options`): `Promise`<`void`\>

**`description`** Redirect to a specified page within the Mini Program.

**`example`**

```ts
bn.redirectTo({
  url: "/pages/example/index",
});
```

| Name          | Type     |
