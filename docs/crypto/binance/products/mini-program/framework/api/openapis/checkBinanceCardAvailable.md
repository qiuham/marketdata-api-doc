# bn.checkBinanceCardAvailable

▸ **checkBinanceCardAvailable**(): `Promise`<`boolean`\>

**`description`** Check whether the user have available card

**`remark`** supported jssdk >= 4.5.0, required advanced action config

**`example`**

```ts
const isBinanceCardAvailable = await bn.checkBinanceCardAvailable();

```
