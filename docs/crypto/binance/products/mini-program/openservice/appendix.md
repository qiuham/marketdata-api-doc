## <a name="SKU Category List"></a>SKU Category List

[CreateSKUInAudit](/products/mini-program/openservice/create-sku-in-audit) and

Values are **case- and spacing-sensitive** and must match exactly as written below (note `eSIM`'s
lower-case `e`, and the `&` — not `and` — in the two-word categories). Any other value is rejected.
