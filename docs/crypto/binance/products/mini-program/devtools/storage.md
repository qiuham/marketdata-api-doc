# Storage Panel

The Storage Panel serves to display the data storage of the current project after utilizing the
[bn.setStorage](/products/mini-program/framework/api#mpservicesetstorage) command.

In the Storage Panel, you can perform tasks such as deleting (by pressing the delete key), adding,
and modifying data directly.
