# Error Code

Business errors on Stock Option Trading endpoints return HTTP `400` (`-1003` returns `429`, `-1004`
returns `503`, and `-1000` may return `500`) with the standard SAPI error envelope:

```json
{
  "code": 497404,
  "msg": "Insufficient buying power. Please reduce the order size or add funds and try again."
}
```

- `code` is an integer and can be: a standard SAPI code (negative); an option business code
  (`497xxx`); a Stocks Trading code (`486xxx`, returned by Cancel Option Order, Cancel All Option
  Orders and Option Order Detail, see [Stocks Trading Error Code](../stocks/error-code.md)); or a
  compliance code (when Place Option Order or Submit Option Exercise fails a compliance check, the
  compliance code and message are returned as-is). **Handle errors by `code`.**
- `msg` is in English. `{0}` in a message is replaced with the actual value (e.g. a number of
  minutes or a strike price).
- **Several codes can share the same `msg`.** For example,
  `The system is temporarily unavailable. Please try again later.` is used by `497001` / `497301` /
  `497305` / `497417` / `497430`, and `This option contract has expired.` is used by `497425`
  (orders) and `497511` (exercise). `msg` is meant for end-user display; handle errors by `code`,
  not by matching `msg`.
- The `errorCode` field of Option Exercise Detail is an option business code (`497xxx`), returned as
  a string.

# 错误代码

股票期权交易接口的业务错误统一返回 HTTP `400`（`-1003` 为 `429`、`-1004` 为 `503`、`-1000` 可能为
`500`），使用标准 SAPI 错误返回格式：

```json
{
  "code": 497404,
  "msg": "Insufficient buying power. Please reduce the order size or add funds and try again."
}
```

- `code`
  为整数，可能为：SAPI 通用码（负数）；期权业务码（`497xxx`）；美股码段（`486xxx`：撤单、全部撤单、订单详情，见[股票交易错误代码](../stocks/error-code.md)）；合规校验码（下单、提交行权未通过合规检查时原样返回合规服务的码与文案）。**程序请按
  `code` 判断**。
- `msg` 为英文文案。文案中的 `{0}` 会替换为实际值（如分钟数、行权价）。
- **多个 `code` 可能共用同一句 `msg`**。如
  `The system is temporarily unavailable. Please try again later.` 对应 `497001` / `497301` /
  `497305` / `497417` / `497430`；`This option contract has expired.` 对应下单的 `497425` 与行权的
  `497511`。`msg` 面向终端用户展示，程序请按 `code` 判断，不要按 `msg` 匹配。
- 「行权详情」的 `errorCode` 字段取值为期权业务码（`497xxx`），以字符串形式返回。
