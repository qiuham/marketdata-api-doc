# Refund Data Fields

When Compliance and Refund Data Sharing is approved and enabled, the following refund-related fields
may be delivered through the existing [order-status webhook](../webhook/webhook.md) payload,
alongside the [User Data Fields](./2.user-data-fields.md).

| Field         | Type   | Remarks                         |
| ------------- | ------ | ------------------------------- |
| refundAddress | string | Refund crypto address (if any)  |
| refundNetwork | string | Network of refund (e.g., ETH)   |
| refundMemo    | string | Refund memo/memo field (if any) |
