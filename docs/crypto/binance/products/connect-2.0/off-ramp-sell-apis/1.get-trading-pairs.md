# Get supported trading pairs

```
POST /papi/v1/ramp/connect/sell/trading-pairs
```

### Request Body

No request body

### Response Body

| **Field**        | **Type**     | **Remarks**          |
| ---------------- | ------------ | -------------------- |
| fiatCurrencies   | string array | fiat currency list   |
| cryptoCurrencies | string array | crypto currency list |

#

### Example

Response:

```json
{
  "success": true,
  "code": "000000",
  "message": "success",
  "data": {
    "fiatCurrencies": ["USD", "EUR", "VND", "AUD", "TWD", "DEFAULT"],
    "cryptoCurrencies": ["BTC", "ETH", "BNB", "USDT", "USDC", "DAI"]
  }
}
```
