# Solana Provider

## Solana Provider API

Binance Web3 Wallet comes with built-in support for Wallet Standard on Solana. To get started,
simply update the [Solana Wallet Adapter](https://github.com/solana-labs/wallet-adapter) to the
latest release. For a demo, check out the
[Wallet Adapter Example](https://anza-xyz.github.io/wallet-adapter/example/).
