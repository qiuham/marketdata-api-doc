# Sui Provider

## Sui Provider API

Binance Web3 Wallet comes with built-in support for Wallet Standard on Sui. To get started, simply
update the [Sui dApp Kit](https://www.npmjs.com/package/@mysten/dapp-kit) to the latest release. For
a demo, check out [Sui dApp Kit](https://sdk.mystenlabs.com/dapp-kit). And if you are using
Typescript, check out
[Sui TypeScript SDK](https://docs.sui.io/guides/developer/first-app/client-tssdk)
